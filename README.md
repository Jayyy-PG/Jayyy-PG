## 👋 About Me

I'm **Jay**, an Informatics student from **Switzerland 🇨🇭** focused on **Application Development**.

I enjoy building modern **full-stack web applications** and **local-first desktop software**, covering frontend development, backend systems, databases, testing and deployment.

I'm currently studying Informatics at **WISS** and continuously building real-world projects alongside my education.

## 🚀 Featured Projects

### 🎓 WISS HUB

A cloud-based career platform connecting WISS IT students with partner companies.

Students can build professional profiles, showcase projects and skills, discover internships and manage applications, while companies can publish positions, review candidates and communicate directly with students.

**Tech Stack:**  
`Next.js 15` `React 19` `TypeScript` `Tailwind CSS` `Supabase` `PostgreSQL` `Zod` `Vitest` `Playwright` `Vercel`

> 🔒 Source repository currently private.

---

### 🎬 GlattTube

A local-first Windows media application for organising, browsing and processing videos, images and audio files.

Features include media playback, playlists, file organisation, video trimming, compression and local media indexing.

**Tech Stack:**  
`Electron` `React` `TypeScript` `SQLite` `FFmpeg`

### 🎯 GGames

A local-first scorekeeping PWA for two players playing real PingPong and Dart matches on a shared device.

**Tech Stack:**  
`Next.js` `React` `TypeScript` `IndexedDB` `Zod` `Vitest` `Playwright`
